# Projeto_Hi-Teach_Underdog
Projeto da faculdade envolvendo desenvolvimento web, banco de dados e engenharia de requisitos.

Para funcionamento do site, é necessário do aplicativo: XAMPP Control Panel:

Link sugerido para download: https://www.apachefriends.org/pt_br/download.html

Agora você pode extrair os arquivos do repositório.

Feito isso, a partir da pasta principal, atualmente como Underdog Project, abra o cmd e execute: pip install -r bibliotecasN.txt

Para o funcionamento, ligue as opções MySql e Apache no xampp, execute o site.py e Live server no Index.html

Qualquer dúvida estou a disposição.
